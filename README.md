## Six people and the entry each one builds first

**The lecturer with forty scripts to mark.** The same six comments account for most of the feedback on any assignment, and they get retyped in full for every student. Stored once and triggered by a short code, they arrive complete, leaving the tutor to write only the sentence that is specific to that piece of work.

**The recruiter running an outbound week.** Introductions, scheduling notes and polite declines are template work with two or three variable lines. Because expansion happens in whichever application has focus, the same keywords serve an email client, a social inbox and an applicant tracking system without being duplicated anywhere.

**The bookkeeper quoting across currencies.** Payment terms and standard invoice wording are pure boilerplate; the figures beside them are not. Conversion of currency values and measurement units happens as you type, so the number is handled in the document instead of in a calculator beside it.

**The administrator who types long paths.** Server addresses, configuration fragments and command sequences are exactly the material that a typo ruins silently. Behind a keyword each one is entered identically every time, which matters far more than the seconds saved.

**The translator working between unit systems.** Measurements crossing from one convention to another are a constant, low-grade tax on attention. Handled during typing they stop breaking concentration, and the terminology that must always be spelled a particular way can live behind keywords too.

**The consultant with three signatures.** Different clients, different footers, different disclaimers, plus a logo image for one of them. Since pictures can be stored the same way sentences are, all three are two keystrokes each.

## The machinery under all six cases

- Short keywords holding text or images, created without ceremony
- Expansion in every OS X and macOS application rather than one privileged editor
- Conversion of currency values and measurement units carried out as the characters appear
- Import from TextExpander, TypeIt4Me and similar tools by dragging the library across
- Replacement fast enough to keep pace with typing instead of interrupting it
- Release 10.2, a $29.99 Productivity licence

Two of those carry more weight than the rest. Universal scope is the first: something that only worked inside one application would be a feature of that application, and it is the identical behaviour everywhere that turns this into muscle memory. The second is how little effort an entry costs to make. A snippet manager mac users must wrestle with gets abandoned by the end of the month; one where adding an item takes a quarter of a minute keeps accumulating value for years.

## If you already own a snippet library

1. Install first and change nothing — the app is happy sitting idle in the background.
2. Drag your TextExpander or TypeIt4Me collection straight in; the migration is meant to be that blunt.
3. Delete the entries you stopped using two jobs ago rather than importing your own archaeology.
4. Rename any keyword that collides with a real word, then live with the result for a week before adding more.
